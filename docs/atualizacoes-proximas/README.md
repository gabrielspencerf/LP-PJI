# Documentação de Atualização — LP Protocolo Claude Jurídico

Este pacote contém a documentação autossuficiente para atualizar a landing page sem depender de specs anteriores.

## Arquivos

1. `00-contexto-e-regras-do-projeto.md`  
   Define produto, posicionamento, regras de compliance, tom e diretrizes gerais.

2. `01-estrutura-de-sessoes.md`  
   Define a sequência final de seções e a função de cada dobra.

3. `02-copy-e-compliance.md`  
   Contém copy recomendada por seção, claims permitidos e claims proibidos.

4. `03-design-system-e-responsividade.md`  
   Define ajustes de tipografia, espaçamento, paleta, cards, mobile e acessibilidade.

5. `04-conteudo-programa-entregaveis-e-oferta.md`  
   Organiza programa do curso, módulos, entregáveis, oferta, garantia e FAQ.

6. `05-plano-de-implementacao-e-checklist.md`  
   Traz plano técnico por etapas, arquivos prováveis e critérios de aceite.

7. `06-prompt-master-para-cursor-ou-ai-studio.md`  
   Prompt principal para executar a atualização no Cursor ou Google AI Studio.

## Uso recomendado

1. Leia o `00` antes de qualquer alteração.
2. Use o `06` como prompt de execução.
3. Consulte os documentos `01` a `05` para validar cada seção.
4. Não use contexto antigo que não esteja nestes arquivos.
5. Não prometa resultado jurídico, segurança absoluta ou substituição da revisão humana.
