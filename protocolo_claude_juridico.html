Módulo 3
Jurisprudência com Claude
4 aulas · ~60 min · diferencial central do curso
⌄
Lógica do módulo: você ensina como usar o Claude pra analisar texto de decisão judicial que o advogado já trouxe — não ensina direito, ensina o fluxo.
3.1
Por que o Claude inventa decisões judiciais — e o fluxo correto
  • Como LLMs funcionam: completam texto de forma plausível, não buscam informação real
  • Por que pedir "cite jurisprudência sobre X" é o erro mais perigoso que existe
  • O fluxo correto: advogado busca a decisão em site oficial → cola o texto → Claude analisa
  • Sites onde o advogado busca a decisão (STJ, STF, TJs) — você não precisa saber usar, só mostrar que existem
📄 fluxograma do uso correto + lista de onde buscar por área
3.2
Como pedir para o Claude resumir e explicar uma decisão judicial
  • Como colar o texto de uma decisão e pedir um resumo estruturado em linguagem simples
  • Prompt de análise: o que foi decidido, por quê, quem ganhou, o que muda na prática
  • Como pedir que o Claude indique se aquela decisão se aplica a um caso parecido
  • Demonstração ao vivo com decisão real copiada do STJ
📄 prompt de resumo de decisão + prompt de verificação de aplicabilidade
3.3
Comparando várias decisões de uma vez no mesmo projeto
  • Como carregar múltiplas decisões num projeto e pedir comparação entre elas
  • Prompt de comparação: o que cada uma decidiu, onde concordam, onde divergem
  • Como pedir que o Claude identifique qual decisão é mais favorável para um lado
  • Como transformar essa comparação em um resumo para o cliente entender
📄 prompt de análise comparativa + template de resumo para cliente
3.4
Usando as decisões analisadas para gerar o texto da peça
  • Como instruir o Claude a usar só o que foi colado — nunca buscar por conta própria
  • Como pedir que o Claude aponte quando está faltando uma decisão para embasar algo
  • Como organizar a saída para o advogado saber de onde veio cada argumento
  • Checklist de verificação antes de usar: o que o advogado precisa conferir manualmente
📄 prompt de geração com rastreabilidade + checklist de verificação pré-uso
